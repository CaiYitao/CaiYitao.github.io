摘要

本研究旨在用深度学习提升基于全切片图像（Whole-Slide Imaging, WSI）的皮肤癌诊断。我们使用了 1108 张 WSI 切片的数据集，类别高度不平衡。我们在双流多示例学习（Dual-Stream Multiple-Instance Learning, DSMIL）框架中引入关键特征自注意力与多头注意力，提出两种新架构，并用稀疏模块改进了 DSMIL Base。

其中 InsightDerm（Top-K 关键特征多头注意力 + DSMIL）在验证集上取得最佳结果；而更简单的 DSMIL Base 在测试集上表现最优。结果表明，把关键特征与多头注意力引入 WSI 诊断系统是有效的。

背景：为什么是多示例学习？

一张 WSI 是千兆像素级的巨幅图像，但通常只有一个切片级标签（良性 / 恶性、亚型）。于是我们把每张切片切成成千上万个小图块（patch），整张切片视为一个「包（bag）」，图块是包里的「示例（instance）」。多示例学习用注意力把图块聚合成切片级判断——而真正起决定作用的，往往只是少数几个关键图块（肿瘤区域）。

方法

  • 注意力多示例学习：以注意力权重聚合图块特征。
  • 双流多示例学习（DSMIL）：一条流找「关键示例」，另一条流衡量其余示例与它的关系。
  • InsightDerm：在 DSMIL 之上引入 Top-K 关键特征多头注意力——只聚焦注意力最高的若干图块，并用多头机制从多个角度刻画它们。
  • 骨干网络对比：ConvNeXt、Vision GNN、Visual Attention Network。

Abstract

This work enhances deep-learning models for skin-cancer diagnosis from Whole-Slide Imaging (WSI). Using a dataset of 1108 WSI slides with strong class imbalance, we develop two new architectures by adding critical-features self-attention and multi-head attention to the Dual-Stream Multiple-Instance Learning (DSMIL) framework, and revise the DSMIL Base with sparse modules.

InsightDerm (Top-K Critical-Features Multi-Head Attention with DSMIL) achieved the best results on the validation set, while the simpler DSMIL Base outperformed on the test set — demonstrating the value of critical features and multi-head attention for WSI-based diagnosis.

Background: why multiple-instance learning?

A WSI is a gigapixel image, yet typically carries a single slide-level label (benign / malignant, subtype). So each slide is tiled into thousands of small patches and treated as a bag, with patches as instances. Multiple-instance learning uses attention to pool patches into a slide-level decision — and only a few critical patches (the tumour region) usually drive that decision.

Method

  • Attention-based MIL: pool patch features with attention weights.
  • Dual-Stream MIL (DSMIL): one stream finds the critical instance, another measures how the rest relate to it.
  • InsightDerm: adds Top-K Critical-Features Multi-Head Attention on top of DSMIL — attend only to the highest-scoring patches, characterised from several heads.
  • Backbones compared: ConvNeXt, Vision GNN, Visual Attention Network.
